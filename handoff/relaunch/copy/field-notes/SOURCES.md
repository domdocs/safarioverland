# Field Notes — self-drive guides: sources and unverified points

Researched 2026-11-09. Official sources (gov.uk FCDO, State Department via AAA) preferred; secondary sources marked. travel.state.gov returned 403 to automated fetches, so US-government wording was not read directly — see each guide.

Convention: **[V]** verified against the source listed · **[S]** secondary source only (travel guide, operator, forum, news) · **[U]** unverified, kept out of the copy or worded as advice/opinion, not fact.

## 2. gravel-roads.md

- [S] Namibia network ~49,203 km, ~8,037 km bitumen (Roads Authority figures as reported) — https://neweralive.na/overview-national-road-network and https://thebrief.com.na/2023/05/roads-authority-to-invest-n-15bn-in-namibia-s-road-network/
